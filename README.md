# Sitio profesional de Fidel Vallejo Gallardo

Sitio estático desarrollado con Quarto y preparado para publicarse mediante GitHub Pages en `https://fvallejog.github.io`.

## Previsualización local

Desde la carpeta del proyecto:

```bash
quarto preview
```

## Construcción completa

```bash
quarto render
```

El sitio generado será almacenado en la carpeta `docs/`.

## Publicación

El repositorio deberá llamarse `fvallejog.github.io`. En GitHub Pages deberá seleccionarse la rama `main` y la carpeta `/docs` como fuente de publicación.
